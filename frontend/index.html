First launch guide

The first check may download a speech recognition model. This can take a while. For first-time users, we recommend the faster model. You can switch to higher accuracy later.

  1. Allow microphone access when your browser asks.
  2. Run System Check if setup feels stuck.
  3. Record a short sentence first.
